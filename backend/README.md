# Backend - Firebase Firestore

Bu papka Firebase backend konfiguratsiyasini o'z ichiga oladi.

## Struktura
```
backend/
├── firebase.json          # Firebase config
├── firestore.rules        # Xavfsizlik qoidalari
├── firestore.indexes.json # Indekslar
└── functions/             # Cloud Functions (keyinroq)
```

## O'rnatish
```bash
npm install -g firebase-tools
firebase login
firebase init
```
