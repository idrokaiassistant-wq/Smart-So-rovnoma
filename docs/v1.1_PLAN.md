# v1.1 Implementation Plan

**Goal:** Enhance admin capabilities and user engagement without compromising privacy.

## 1. In-App Feedback System
**User Story:** As a user, I want to report bugs or suggest features anonymously so the app improves.

### Implementation Details
*   **UI:** New "Feedback" item in `SettingsScreen`. Opens a simple form (Text Area + Submit).
*   **Data Model:**
    ```json
    {
      "content": "String (max 500 chars)",
      "timestamp": "ServerTimestamp",
      "appVersion": "String (e.g., 1.0.0)",
      "deviceInfo": "String (e.g., Android 13, SDK 33) - Generic only",
      "language": "String (uz/ru/en)"
    }
    ```
*   **Storage:** Firestore collection `feedback`.
*   **Security:**
    *   `allow create: if true;` (Public write)
    *   `allow read: if isAdmin();` (Admin only)
    *   **Rate Limit:** Client-side 5-minute cooldown (SharedPrefs).

## 2. Admin Export CSV
**User Story:** As an admin, I want to download survey results to Excel/CSV for deep analysis.

### Implementation Details
*   **UI:** "Export" button on Survey Detail page in Admin Panel.
*   **Logic:**
    *   Fetch all `responses` for `surveyId`.
    *   Map question IDs to question text.
    *   Format as CSV: `Date, Question 1, Question 2, ...`
    *   Trigger browser download (`blob`).
*   **Privacy:** Ensure no Metadata (IP, User ID) is exported (since we don't collect it anyway).

## 3. Role-Based Access Control (RBAC)
**User Story:** As an organization, I want to give "Viewer" access to stakeholders without letting them edit surveys.

### Implementation Details
*   **Roles:**
    *   `admin`: Full access (Create/Delete/Edit/View).
    *   `editor`: Can Edit surveys, cannot Delete or Manage Users.
    *   `viewer`: Read-only access to Results and Surveys.
*   **Firestore Data:**
    *   Collection `users/{uid}` with field `role: "admin" | "editor" | "viewer"`.
*   **Security Rules:**
    ```javascript
    function getUserRole() {
      return get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role;
    }
    
    allow read: if request.auth != null;
    allow write: if getUserRole() == 'admin';
    // Granular rules for specific collections
    ```
